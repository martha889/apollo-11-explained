# Web Fonts

These web fonts were sourced from Google Fonts (https://fonts.google.com/):
- Barlow Condensed (weights 500, 600, 700)
- IBM Plex Mono (weights 400, 500, 600)
- IBM Plex Sans (one variable font covering weights 400 to 600)

Only the Latin character subset (.woff2) for normal font styles is bundled.
